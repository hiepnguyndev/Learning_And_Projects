# Nguyễn Duy Hiệp — CV cá nhân

## Cách mở nhanh

Mở trực tiếp file `index.html` bằng trình duyệt.

## Cách chạy bằng local server

Mở Terminal/PowerShell tại thư mục này rồi chạy:

```bash
python -m http.server 8000
```

Nếu máy dùng Windows và lệnh trên không hoạt động, thử:

```bash
py -m http.server 8000
```

Sau đó truy cập: <http://localhost:8000>

Website không cần cài thêm thư viện hay kết nối cơ sở dữ liệu.
